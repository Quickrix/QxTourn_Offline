# QxTourn_Offline
- Приложение _QxTourn Offline_ является надстройкой к сайту **QxTourn** - онлайн системе для проведения турниров, это не самостоятельный продукт.
- Для проведения турнира приложению требуются данные с сайта **QxTourn**. Их можно передать онлайн или посредством экспорта через json-файл.
- Для проведения турнира _QxTourn Offline_ интернет не обязателен: посев, настройки сеток, ввод счёта, заявки, новые игроки - это всё будет работать.
- При наличии интернета _QxTourn Offline_ будет автоматически синхронизировать всю информацию по турниру на сайт, будет работать механизм оповещения игроков о вызовах на корт.
- По окончании игрового дня и когда появится интернет на вашем компьютере в _QxTourn Offline_ на странице «Синхронизация» нажмите «Выгрузить результаты на сайт». Будет произведена выгрузка (синхронизация) данных на сайт.


## Возможности приложения QxTourn Offline
1. **Игры**: полный функционал по ведению сеток игр, начиная от посева и параметров. Это один-в-один копия системы на сайте **QxTourn**.
2. **Заявки**: переносятся с сайта **QxTourn**, кроме удаленных и неполных (включая неподтвержденных напарников). Лучше обработать все заявки на сайте перед экспортом.
3. **Заявки**: доступны стандартные операции по изменению статусов (подтвердить, удалить, в ожидание). Эти изменения будут перенесены на сайт при синхронизации.
4. **Игроки**: данные экспорта содержат полную базу игроков («справочник») и их ЛАБ рейтинги. Телефоны маскированы (для защиты).
5. **Игроки**: можно добавить в «справочник» новых игроков, полностью заполнив форму данными. При синхронизации они будут добавлены в базу сайта после процедуры сверки.
6. **Заявки**: возможно добавление новых заявок, как из известных игроков (из «справочника»), так с добавлением новых (добавятся в «справочник»).
7. **Импорт данных на сайт**: синхронизирует данные по заявкам, свойствам игровых бюллетеней и полностью перезаписывает все данные по игровым бюллетеням по всему турниру из дампа данных из _QxTourn Offline_.
8. **Авторизация**: в _QxTourn Offline_ действует свой пароль, пароли с сайта никак не задействованы. По сути это формальная защита.

## Известные проблемы и решения
- В приложении могут стать не редактируемыми поля для ввода: переключитесь в любое другое открытое приложение на компьютере и обратно в _QxTourn Offline_.
- При возникновении проблем с приложением можно выполнить полный сброс данных - внизу страницы «Синхронизация». Это полностью удалит все локальные данные. При необходимости - сохраните их сначала в файл.
